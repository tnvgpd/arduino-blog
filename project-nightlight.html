Automated Nightlight

Arduino Sensors LED

The Sensor-Based Nightlight is an automated lighting system that activates an LED in dark environments. It serves as a practical demonstration of integrating analog inputs with digital outputs.

The Build Process

I used an Arduino UNO Q board and a Grove Light Sensor. The light sensor is connected to an analog pin to continuously read the ambient light levels. Based on testing, I established an optimal threshold value of 900. When the analog reading exceeds this threshold (indicating low light), the Arduino sends a signal to automatically turn on the LED.

Lessons Learned

This project taught me how to read and interpret analog sensor data. I discovered that the Grove Light Sensor outputs higher values in darker environments, which was critical for writing the if-else logic to control the LED properly. Using Serial.print() was incredibly helpful for debugging and finding the exact threshold required for a typical room.
